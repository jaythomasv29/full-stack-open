participant browser
participant server

    Note right of browser: User writes a new note to add into input field and clicks Save button

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note

    Note left of server: Server saves the new note in db

    server-->>browser: 302 Found HTTP status - Redirect to /exampleapp/notes, the main page
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate server
    server-->>browser: CSS file
    deactivate server

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate server
    server-->>browser: JavaScript file
    deactivate server

    Note right of browser: Browser executes JavaScript code and requests the notes data

    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
    activate server
    server-->>browser: Server serves back JSON containing all notes, including the new note
    deactivate server

    Note right of browser: JavaScript renders the newly updated notes list with the new note added
